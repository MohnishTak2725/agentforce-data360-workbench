🛠️ Capstone Project: "Project AeroPulse — Autonomous VIP Concierge"

Trainees build a complete, production-ready enterprise solution inside their developer sandboxes. Fulfills the practical criteria of both the Flow Administration for Agentforce and Apex for Agentforce superbadges.

Milestone 1 • Data Cloud
Ingestion & DMO Mapping
Ingest sample flight & booking CSVs into Data Lake Objects (`__dll`) and map to standard `ssot__Individual__dlm` and `ssot__Account__dlm`.
Milestone 2 • Identity & Insights
Golden Record & LTV Insight
Configure match rules on normalized email. Write an ANSI SQL Calculated Insight to calculate customer delay frequency and spend tier.
Milestone 3 • Prompt Builder
Grounded Flex Templates
Create a dynamic `VIP_Lounge_Pass_Offer` template grounded on Contact and Flight records, enforcing polite, zero-hallucination guardrails.
Milestone 4 • Apex Invocable
Lounge Pass Issuer Action
Write `IssueLoungePassAction.cls` with bulkified list contracts, `with sharing` FLS checks, and structured error reporting (`isSuccess`, `outcomeMessage`).
Milestone 5 • Agentforce Builder
Agent Assembly & Topics
Assemble the AeroPulse Concierge agent, configuring Flight Status and VIP Perks topics, instructions, negative boundaries, and action bindings.
Milestone 6 • Security & QA
Trust Layer Audit & Red-Teaming
Run adversarial tests (Indirect Prompt Injections) in the Testing Center and take screenshots verifying PII masking in Trust Layer audit logs.
