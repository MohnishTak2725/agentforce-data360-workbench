## 📚 Curriculum & Architecture Covered (16 Modules)

### Part I: Agentforce Autonomous Architecture
1. **Autonomous AI & The Atlas Engine**: ReAct (Reason + Act) loop, model planning, Model Builder (BYO-LLM).
2. **Topics & Scope Engineering**: Dynamic intent classification, instruction boundaries, guardrails.
3. **Agent Actions**: Apex Invocables, Flows, Prompt Templates, MuleSoft APIs.
4. **Apex `@InvocableMethod` Engineering**: Structured error handling, DTO design, bulkification.

### Part II: Data Cloud & Harmonization
5. **Data Cloud Ingestion**: Connectors, Data Streams, raw Data Lake Objects (`__dll`).
6. **Canonical Data Modeling**: Customer 360 DMOs (`__dlm`), Data Spaces.
7. **Identity Resolution**: Deterministic/probabilistic matching, Golden Record (`UnifiedIndividual__dlm`).
8. **Calculated Insights**: Batch Spark vs. streaming Flink ANSI SQL analytics (`__cio`).
9. **Sub-Second Data Graphs**: Hierarchical JSON pre-materialization for conversational latency.
10. **Vector RAG & Hybrid Search**: BM25 lexical + dense vector search with Reciprocal Rank Fusion (RRF).
11. **Zero Copy Lakehouse Federation**: Apache Iceberg integration with Snowflake, BigQuery, Databricks.

### Part III: Enterprise Security, Testing & Pro-Code Development (2026 Additions)
12. **Einstein Trust Layer**: Dynamic PII masking/de-masking, Zero Data Retention (ZDR), toxicity defense.
13. **Threat Modeling & Prompt Defense**: STRIDE for agents, Direct vs. Indirect Prompt Injection (IPI) in CRM data, Confused Deputy mitigation in Apex `with sharing`.
14. **Agentforce Testing Center & Semantic Evaluation**: Golden Test Datasets, batch regression suites, topic classification accuracy, and hallucination scoring.
15. **Autonomous SDR, Sales Coach & Voice Architecture**: 24/7 lead qualification, interactive roleplay simulations (MEDDPICC), Service Cloud Voice, Voice Gateway, and <1,000ms latency budgeting.
16. **Pro-Code Developer Stack**: Agentforce DX metadata (`GenAiPlanner`, `GenAiPlugin`, `GenAiFunction`), headless REST Agent API, and native Apex `aiplatform.ModelsAPI`.
